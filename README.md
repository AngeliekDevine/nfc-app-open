# yahtzyy Scorecard PWA

- Unlimited players
- Explicit Virtual Dice / Physical Dice mode selection
- Virtual dice: three rolls, holds, automatic category suggestions
- Physical dice: use real dice and record scores manually
- Edit Scores mode lets you enter or change any score at any time
- Automatic upper-section bonus and totals
- Offline PWA with localStorage

Run locally with `python -m http.server 8000` and open `http://localhost:8000`.
